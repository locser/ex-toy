# Tổng Quan Tài Liệu Dự Án

Tài liệu này phác thảo các tài liệu chính cho dự án Nền Tảng Trao Đổi Đồ Chơi.

## 1. Tài Liệu Yêu Cầu Kinh Doanh (BRD)

- **Vị trí:** `BRD.md` (hoặc liên kết đến tài liệu/wiki bên ngoài)
- **Mục đích:** Mô tả mục tiêu kinh doanh cấp cao, đối tượng mục tiêu, phạm vi và các chỉ số thành công của dự án.

## 2. Tài Liệu Yêu Cầu Chức Năng (FRD) / User Stories

- **Vị trí:** `requirement.md` (hoặc liên kết đến user stories cụ thể trong công cụ quản lý dự án)
- **Mục đích:** Chi tiết các tính năng và chức năng cụ thể mà hệ thống phải cung cấp từ góc độ người dùng. Bao gồm đăng ký người dùng, đăng đồ chơi, tìm kiếm, khởi tạo trao đổi, v.v.

## 3. Yêu Cầu Phi Chức Năng (NFRs)

- **Vị trí:** `requirement.md` (hoặc file `NFRs.md` riêng)
- **Mục đích:** Xác định các thuộc tính chất lượng của hệ thống, như hiệu suất, bảo mật, khả năng sử dụng, độ tin cậy và khả năng bảo trì.

## 4. Tài Liệu Kiến Trúc Hệ Thống

- **Vị trí:** (Sẽ được tạo, ví dụ: `Architecture.md` hoặc sơ đồ trong `/docs/architecture/`)
- **Mục đích:** Mô tả cấu trúc tổng thể của hệ thống, bao gồm các thành phần, công nghệ (Spring Boot, Database, v.v.), API và luồng dữ liệu.

## 5. Tài Liệu API

- **Vị trí:** (Sẽ được tạo hoặc sinh tự động, ví dụ: sử dụng Swagger/OpenAPI)
- **Mục đích:** Chi tiết các API RESTful được cung cấp bởi backend, bao gồm các endpoint, định dạng request/response và phương thức xác thực.

## 6. Hướng Dẫn Triển Khai

- **Vị trí:** (Sẽ được tạo, ví dụ: `Deployment.md`)
- **Mục đích:** Cung cấp hướng dẫn về cách xây dựng, cấu hình và triển khai ứng dụng cho các môi trường khác nhau (phát triển, staging, production).
